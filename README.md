# 🌱 Spring Boot Learning

A structured repository documenting my journey of learning **Spring Boot** from fundamentals to advanced backend development.

---

## 📖 About

This repository contains all my Spring Boot learning projects, organized topic by topic. Each folder represents a separate concept or mini-project, allowing me to track my progress and build a strong foundation in Spring Boot.

The focus of this repository is not only to write code but also to understand the internal working of Spring Boot, Spring MVC, Tomcat, Servlets, Dependency Injection, and related backend technologies.
